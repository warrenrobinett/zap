# MathZap

A game that teaches algebra via buildable math machines. Numbers flow through
operators; expressions shape-shift between tree, string, and pure text.
By Warren Robinett.

## Getting MathZap

MathZap is distributed to invited players. If you received an invitation, it
contains your personal download link and your **activation code** — the app
asks for the code the first time it runs.

Once you have your invitation:

1. Download the `.soul.zip` using the link in your invitation (it brings you
   to this repository's latest release).
2. Unzip it, then run the installer for your platform:

| Platform | Do this |
|---|---|
| macOS    | double-click `INSTALL.command` |
| Windows  | double-click `INSTALL.bat` (if SmartScreen objects: *More info → Run anyway*) |
| Linux    | `sh install.sh` |

3. When the app first opens, enter the activation code from your invitation.

The installer fetches the game engine (Godot, from its official releases),
installs the app, and launches it. Each release page lists the `sha256` of its
zip if you want to check integrity.
