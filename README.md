# MathZap

A game that teaches algebra via buildable math machines. Numbers flow through
operators; expressions shape-shift between tree, string, and pure text.
By Warren Robinett.

## Download

**[⬇ Get the newest version](https://github.com/warrenrobinett/zap/releases/latest)** —
download the `.soul.zip` from the latest release, unzip it, then run the
installer for your platform:

| Platform | Do this |
|---|---|
| macOS    | double-click `INSTALL.command` |
| Windows  | double-click `INSTALL.bat` (if SmartScreen objects: *More info → Run anyway*) |
| Linux    | `sh install.sh` |

The installer fetches the game engine (Godot, from its official releases),
installs the app, and launches it. Each release page lists the `sha256` of its
zip if you want to check integrity.

*This repository hosts releases only — the source lives elsewhere.*
